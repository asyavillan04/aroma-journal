# Aroma Journal

This is a pet project in progress. App for tracking perfumery ingridients and organizing formulas. 
For Web, Windows and Android.

Stack: HTML, CSS, JS (frontend) + C# (backend)

Users will be able to:
- Control what ingridients they have and in what amount (done)
- Organize different perfume projects and formulas (in progress)
- Track maceration of perfumes 
- Add notes about different ingridients (done)
- Add notes about different variations of the same project (done)
- Use library of most important ingridients for quick search... (function done, library in progress)
- ...or add ingridient if it doesnt exist in the library (done)
- Build olfactory pyramid of the formulas 
- Calculate weight of ingridients for any amount of perfume they need
- See warnings about IRFA restrictions

[Demo on Git Pages](https://asyavillan04.github.io/aroma-journal/)

Planned interface languages: English, Spanish, Russian, Esperanto (currently Russian only)
